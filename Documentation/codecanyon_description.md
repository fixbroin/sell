<h2>Yourbrand | Handyman and Home Services Booking Web App - On-Demand Marketplace Platform (Next.js + MySQL)</h2>

<p>Yourbrand is a complete on-demand handyman and home services marketplace built with Next.js, MySQL and Firebase Authentication. It includes a customer website, provider panel and powerful admin panel with advanced booking automation, provider wallet and commission management, SEO tools, provider management, payment integrations, analytics and business management features.</p>


<h2>Three Separate PWA Apps Included</h2>

<p>Yourbrand includes <strong>three separate Progressive Web Apps (PWAs)</strong>, each designed for a different user role. They can be installed individually on supported devices and used like an app, without requiring a separate native Android or iOS application.</p>

<ul>
  <li><strong>Customer PWA:</strong> A dedicated installable PWA for customers to browse services, book services, manage bookings, make payments and use customer features.</li>
  <li><strong>Provider PWA:</strong> A dedicated installable PWA for service providers to manage jobs, bookings, availability, earnings, wallet and provider features.</li>
  <li><strong>Admin Panel PWA:</strong> A dedicated installable PWA for administrators to manage bookings, providers, services, payments, settings, reports and the complete marketplace.</li>
</ul>

<p><strong>Each PWA works independently according to its user role and can be installed separately on supported devices for an app-like experience.</strong></p>

<h2>Provider Wallet &amp; Commission Management</h2>

<p>The provider wallet system helps marketplace administrators manage provider balances, platform commissions and payout workflows.</p>

<ul>

<li>
<strong>Wallet Balance Gate:</strong>
Administrators can define a minimum wallet balance required for providers to receive or accept new jobs.
</li>

<li>
<strong>Commission Management:</strong>
Platform commission rules can be configured by the administrator and applied to completed service transactions.
</li>

<li>
<strong>Earnings Ledger:</strong>
Providers can view their earnings, commissions, wallet transactions and payout-related information.
</li>

<li>
<strong>Withdrawal Requests:</strong>
Providers can submit withdrawal requests through their provider panel.
</li>

<li>
<strong>Admin Payout Management:</strong>
Administrators can review and manage provider withdrawal requests.
</li>

<li>
<strong>Wallet Refund Protection:</strong>
When an applicable withdrawal request is rejected or cancelled, the corresponding amount can be returned to the provider wallet according to the system workflow.
</li>

<li>
<strong>Platform Fee Management:</strong>
Administrators can configure platform fee and minimum wallet balance settings.
</li>

</ul>

<h2>Database Architecture</h2>

<p>The application uses <strong>MySQL as the primary application database</strong> for users, providers, bookings, services, wallet transactions, payments, settings, SEO data, reports and other application records.</p>

<p><strong>Firebase is used for authentication-related functionality</strong>, such as supported login and authentication methods. Application business data is not dependent on the Firebase database.</p>
